CS491 / CS492 Senior Design Project · Bilkent University

TRACED

Turkish Retrieval-Augmented Claim Evaluation and Detection

Pronounced like the English word “traced” (/treɪst/)

About

We propose an analyst web application that discovers Turkish claims in X (Twitter) posts, investigates them using external evidence, and tracks how they spread and change over time. It shows fact-checkers which claims are spreading fastest, so they know what to check first, while a person always makes the final decision. The project combines a working platform with a Turkish evidence-ranking model that we train ourselves and a measured evaluation against simpler baselines.
